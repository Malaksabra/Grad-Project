## Grad Project 

## About the Project

It is an interactive learning application designed to support children with autism in developing communication skills, learning daily routines, and understanding social situations.

## Project Goals

- Support communication and expression.
- Help children learn daily routines step by step.
- Improve understanding of everyday social situations.
- Provide interactive learning activities in a child-friendly environment.

## Main Features

- **Communication:** Activities that help children express their needs and choices.
- **Daily Routines:** Step-by-step activities for everyday tasks.
- **Social Situations:** Activities that help children understand common social interactions.

## Technologies

- Flutter
- Dart

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/downloads)
- [Flutter](https://docs.flutter.dev/get-started/install) version **3.32.4** (stable). Do not upgrade Flutter without telling the team.
- Google Chrome (to run the app on the web during development)

Check that everything is installed:

```bash
git --version
flutter --version
```

### Run the app

```bash
git clone https://github.com/Malaksabra/Grad-Project.git
cd Grad-Project/mobile
flutter pub get
flutter run -d chrome
```

Always run Flutter commands from inside the `mobile` folder.
